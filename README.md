# 每日 Rust 一课

系统学习 **Rust** 的语法原理、规则细节与最佳实践。
每天晚上 **19:00**（Asia/Shanghai），DeepSeek Harness 的定时任务自动生成新的一课
（任务保存在宿主中：Session 关闭也会在到期时恢复并投递；宿主重启后会补投
最近错过的一次，不会因为某天没开机而断课）。任务可在 Web GUI 的
「自动化任务」页面查看、改时间或删除。

## 目录结构

按学习阶段分顶层文件夹，每课一个独立子文件夹（`编号_中文主题/`），
内含同名 `.md` 讲解 + 同编号 ASCII 命名的独立 `.rs`：

```
README.md                                  —— 课程大纲与进度（本文件）

  ...
ABSTRACTION/                               —— 第二部分（第 12–21 课）：泛型、trait 与迭代器
ERRORS/                                    —— 第三部分（第 22–30 课）：错误处理与工程化
CONCURRENCY/                               —— 第四部分（第 31–39 课）：线程、原子与异步
ADVANCED/                                  —— 第五部分（第 40–47 课）：unsafe、宏与性能
```

## 每课固定结构

讲解（Markdown）与代码（独立 `.rs`）分离。讲解固定三段式：

1. **一、底层原理** —— 编译器/运行时视角：这个语法被翻译成什么代码、解决了什么旧问题、
   与其他语言写法的本质对比
2. **二、具体语法** —— 语法形式、规则细则、能做与不能做
3. **三、实际应用与最佳实践** —— 真实工程场景 + 最佳实践清单
4. 末尾附 **常见陷阱 / 练习 / 参考**

`.rs` 示例按 `① 原理验证 → ② 语法演示 → ③ 应用实战` 三段组织，
**只依赖标准库**（单文件即可编译，不需要 Cargo 与外部 crate），
每处输出附预测注释，输出保持 ASCII，规避 Windows 控制台编码问题。

## 如何学习

1. 读 Markdown 讲解，理解每项语法的**动机**（它解决了什么问题、编译器为它做了什么）
2. 打开配套 `.rs`，先**自己预测输出**，再编译运行对照
3. 完成课末练习；想深入某个主题，可对照 `notes/` 里的 B 站视频笔记

## 编译运行

本机工具链：**rustc 1.92.0**（stable-x86_64-pc-windows-msvc），示例统一使用
`edition 2024`（需要 rustc 1.85+；路径含中文记得加引号）：

```bash
# 编译（-D warnings 把警告升级为错误，零警告才算通过）
rustc --edition 2024 -D warnings "BASICS/01_变量绑定与可变性/01_bindings_and_mutability.rs" -o run.exe

# 运行
./run.exe
```

每课的验收标准有两条：**编译零警告**，且**实际输出与注释里的预测逐行一致**。
