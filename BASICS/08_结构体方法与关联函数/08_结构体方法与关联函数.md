# 第 08 课 · 结构体、方法与关联函数

> 所需工具链：rustc 1.85+（edition 2024） ｜ 讲解：本文件 ｜ 独立代码：`08_structs_and_methods.rs`

## 一、底层原理

### 8.1 三种结构体与内存布局

Rust 的结构体有三种形态：

| 形态 | 定义 | 访问 | 典型用途 |
|---|---|---|---|
| 命名结构体 | `struct Point { x: i32, y: i32 }` | `p.x` | 有明确字段语义的数据 |
| 元组结构体 | `struct Meters(f64)` | `m.0` | newtype、轻量包装 |
| 单元结构体 | `struct Marker;` | 无字段 | 标记类型、零大小类型 |

布局上要记住三件事：

- **字段直接内联**：`struct Pair { a: u32, b: u32 }` 就是 8 字节，没有"每个字段一个指针"的开销
- **`repr(Rust)` 允许编译器重排字段**以减少 padding。示例里
  `struct Mixed { u8, u32, u8 }` 是 **8 字节**，而同样字段的 `#[repr(C)]` 版本是 **12 字节**
- **`#[repr(C)]` 保证声明顺序与 C ABI**，用于 FFI；`#[repr(transparent)]` 用于
  单字段 newtype（保证与内部字段相同的布局/ABI）；`#[repr(packed)]` 会制造未对齐引用，
  除非非常清楚在做什么，否则不要用

空结构体（`struct Marker;` 或 `struct Empty {}`）是**零大小类型（ZST）**：
`size_of == 0`、`align_of == 1`。`Vec<Marker>` 不占数据空间，常用作类型级标记。

结构体**没有继承**。需要"复用行为"时用 trait（第 13 课）和组合，而不是父类。

### 8.2 方法只是"第一个参数是 self 的函数"

`impl` 块不产生任何运行期数据，也不改变类型大小。方法在编译期被翻译成普通函数：

```rust
impl Rectangle {
    fn area(&self) -> u32 { self.width * self.height }
}
// 约等于
fn area(self: &Rectangle) -> u32 { ... }
```

`impl` 里可以放三类东西：

| 种类 | 语法 | 有没有 self | 调用方式 |
|---|---|---|---|
| 方法 | `fn area(&self)` | 有 | `rect.area()` |
| 关联函数 | `fn new(w: u32, h: u32) -> Self` | 无 | `Rectangle::new(3, 4)` |
| 关联常量 | `const SIDES: u32 = 4;` | 无 | `Rectangle::SIDES` |

接收者（receiver）决定方法拿到的权限：

| 接收者 | 拿到什么 | 调用后原值 | 典型命名 |
|---|---|---|---|
| `self` | 所有权 | 被移动 | `into_*`、`consume` |
| `&self` | 共享借用 | 仍可用 | `area`、`len`、`get` |
| `&mut self` | 可变借用 | 仍可用，可被修改 | `push`、`scale`、`update` |
| `self: Box<Self>` | 堆上的所有权 | Box 被消费 | 较少见 |
| `self: Rc<Self>` / `Arc<Self>` | 共享所有权 | 计数变化 | 共享服务对象 |
| `self: Pin<&mut Self>` | 固定地址的可变借用 | 不可移动 | 异步/自引用（第 37 课） |

**方法解析顺序**：先自动解引用/自动取引用找**固有方法**（inherent method），
找不到再找 trait 方法。这就是"固有方法优先"；需要显式调用 trait 版本时用
UFCS：`Trait::method(&value)`。

固有方法走**静态分发**，可以被内联；只有 `dyn Trait` 才通过 vtable 动态分发（第 16 课）。

### 8.3 构造器不是语言特性

Rust 没有构造函数关键字。`Rectangle::new(3, 4)` 只是一个**返回 `Self` 的关联函数**，
`new` 只是社区约定。常见的构造入口：

| 写法 | 含义 |
|---|---|
| `Type::new(...)` | 常规构造 |
| `Type::with_capacity(n)` | 预分配容量 |
| `Type::from_*(...)` | 从别的类型转换 |
| `Default::default()` | 全默认值 |
| `Type { field: ..., ..Default::default() }` | 只写关心的字段 |

构造器可以**校验不变量**，返回 `Option<Self>` / `Result<Self, E>`：

```rust
struct Celsius(f64);
impl Celsius {
    fn new(value: f64) -> Option<Self> {
        (value >= -273.15).then_some(Self(value))   // 非法状态构造不出来
    }
}
```

### 8.4 结构体更新语法与部分移动

```rust
let dev = Config { host: String::from("dev"), ..base };
```

`..base` 把**没有显式给出的字段**从 `base` 搬过来：

- 非 `Copy` 字段（如 `String`）会被**移动**，`base` 进入"部分移动"状态
- `Copy` 字段（如 `u16`、`u8`）是复制，`base.port` 之后仍然可用
- 但 `base` 整体不能再使用；如果 `base` 实现了 `Drop`，连部分移动都不允许（E0509）

这也是"结构体更新语法"和"克隆"的本质区别：前者是移动，后者是复制。

### 8.5 方法接收者与借用检查

```rust
let mut rect = Rectangle::new(3, 4);
rect.scale(2);                 // &mut self
println!("{}", rect.area());   // &self
let dims = rect.into_dimensions();  // self：rect 被移动
```

- `&mut self` 要求绑定本身是 `mut`，否则 E0596
- `self` 方法调用后原值不可用，再用就是 E0382
- 同一个表达式里同时调用 `&self` 和 `&mut self` 方法会冲突（E0502），拆成两条语句即可
- 方法的自动借用让 `rect.area()` 不需要写 `Rectangle::area(&rect)`，
  但 UFCS 形式在排查名字冲突时很有用

### 8.6 newtype：把语义编进类型

```rust
struct Meters(f64);
struct Seconds(f64);

fn speed(distance: Meters, time: Seconds) -> f64 { distance.0 / time.0 }
// speed(Seconds(1.0), Meters(2.0)) 会直接编译失败
```

newtype 是**零成本**的：`Meters` 与 `f64` 布局相同（想对 FFI 保证这一点就加
`#[repr(transparent)]`）。它解决的问题是"两个 `f64` 在类型上无法区分"——
单位、ID、金额、坐标都能这样包装。

newtype 还可以为外部类型添加**本地方法/trait**（因为类型是本地定义的，
不受孤儿规则限制，第 13 课）。

### 8.7 泛型结构体

```rust
struct Stack<T> { items: Vec<T> }

impl<T> Stack<T> {
    fn new() -> Self { Self { items: Vec::new() } }
    fn push(&mut self, item: T) { self.items.push(item); }
}
```

- 结构体定义引入 `T`，`impl` 块要重复声明 `impl<T>`
- 方法需要额外能力时，在 `impl` 上加约束：`impl<T: Ord> Stack<T> { ... }`，
  这样只有满足约束的 `T` 才能调用这些方法
- 泛型在编译期**单态化**：每个具体 `T` 生成一份代码（第 12 课）

## 二、具体语法

### 9.1 定义与实例化

```rust
struct Point { x: i32, y: i32 }

let p = Point { x: 3, y: 4 };      // 字段必须写全
let q = Point { x: 0, ..p };       // 更新语法：其余字段从 p 来
println!("{}", p.x);               // 若 p.x 是 Copy，仍可用
```

- 字段顺序在字面量里可以任意
- 缺少字段（且没有 `..`）是编译错误
- 字段缩写：`Point { x, y }`（变量名与字段名相同时）

### 9.2 元组结构体与单元结构体

```rust
struct Meters(f64);                // 访问 .0
struct Marker;                     // 无字段，值就是 Marker

let m = Meters(12.5);
println!("{}", m.0);
```

- 元组结构体字段按 `.0`、`.1` 访问，不能按名字访问
- 单字段元组结构体是 newtype 的标准写法
- 单元结构体可以直接当值用：`let _ = Marker;`

### 9.3 方法与关联函数

```rust
impl Rectangle {
    const SIDES: u32 = 4;                       // 关联常量

    fn new(width: u32, height: u32) -> Self {   // 关联函数
        Self { width, height }
    }

    fn area(&self) -> u32 { self.width * self.height }

    fn scale(&mut self, factor: u32) {
        self.width *= factor;
        self.height *= factor;
    }

    fn into_dimensions(self) -> (u32, u32) {    // 消费 self
        (self.width, self.height)
    }
}
```

- `Self` 指"当前 impl 的类型"，在泛型里会展开成具体实例
- 关联函数用 `Type::func()` 调用；当第一个参数是 `self` 时才叫方法
- 方法可以分在多个 `impl` 块里，编译器会合并
- 关联常量属于类型，不占实例空间

### 9.4 调用形式与 UFCS

```rust
rect.area();                    // 方法调用（自动借用）
Rectangle::area(&rect);         // 完全限定语法（UFCS）
Rectangle::new(3, 4);           // 关联函数
Rectangle::SIDES;               // 关联常量
```

UFCS 在两种场景下必用：固有方法与 trait 方法同名、或被自动解引用"抢走"了调用。

### 9.5 `Default` 与派生

```rust
#[derive(Debug, Clone, PartialEq)]
struct Options { verbose: bool, retries: u8, label: String }

impl Default for Options {
    fn default() -> Self {
        Self { verbose: false, retries: 3, label: String::from("default") }
    }
}

let opts = Options { verbose: true, ..Options::default() };
```

- `#[derive(Default)]` 要求所有字段都实现 `Default`；有特殊默认值时手动实现
- `#[derive(Debug, Clone, PartialEq, Eq, Hash)]` 是最常见的组合
- `Debug` 给开发者看，`Display` 需要手写（第 17 课）

### 9.6 泛型结构体与 `impl`

```rust
struct Stack<T> { items: Vec<T> }

impl<T> Stack<T> {
    fn new() -> Self { ... }
    fn push(&mut self, item: T) { ... }
}

impl<T: Ord> Stack<T> {
    fn push_sorted(&mut self, item: T) { ... }   // 只有 T: Ord 时可用
}
```

### 9.7 可见性（预览）

字段默认是**私有**的（模块级可见性，第 11 课展开）：

```rust
pub struct Account {
    pub owner: String,   // 外部可读
    balance: i64,        // 只有本模块能访问
}
```

私有字段 + 公开方法 = 封装。外部无法直接改 `balance`，只能走
`deposit`/`withdraw`，不变量就守住了。

## 三、实际应用与最佳实践

### 10.1 领域模型：方法把业务规则收进类型

```rust
let mut account = Account::new("alice", 100);
println!("{:?}", account.deposit(50));   // Ok(150)
println!("{}", account.withdraw(30));    // true
println!("{}", account.withdraw(1000));  // false
```

`deposit` 用 `checked_add` 防溢出、`withdraw` 先检查余额，调用方不需要知道细节。
**方法应该表达业务动作，而不是暴露字段**。

### 10.2 newtype + 智能构造器

```rust
let valid = Celsius::new(36.6);      // Some(Celsius(36.6))
let invalid = Celsius::new(-300.0);  // None（低于绝对零度）
```

把"值必须 ≥ -273.15"这条不变量放进构造函数，之后所有 `Celsius` 实例都自动合法。
比起在每处调用点检查，这种"构造即校验"更可靠。

### 10.3 泛型结构体：一份代码服务所有 T

```rust
let mut stack: Stack<i32> = Stack::new();
stack.push(1);
stack.push(2);
```

`Stack<T>` 的 `push`/`pop`/`len` 对所有 `T` 都成立，不需要为每种类型复制代码。
需要 `T: Ord` 的方法单独放在带约束的 `impl` 里。

### 10.4 配置更新与 `Default`

```rust
let opts = Options { verbose: true, ..Options::default() };
```

只写关心的字段，其余取默认值。比写一个全是 `None`/`0` 的长字面量清晰，
也比"先 `mut` 再逐个赋值"更安全。

### 10.5 最佳实践清单

1. **有名字的字段优先**：元组结构体只用于 newtype/轻量包装
2. **方法接收者表达意图**：`&self` 查询、`&mut self` 修改、`self` 消费
3. **构造器负责校验不变量**：非法状态在 `new` 里返回 `None`/`Err`
4. **字段默认私有**，通过方法暴露受控操作
5. **`new` 只是约定**：可以有多个构造入口，但命名要能说明区别
6. **`Default` 用更新语法**：`Type { x: 1, ..Default::default() }`
7. **不要依赖 `repr(Rust)` 的字段顺序**：FFI/序列化用 `#[repr(C)]` 或显式编码
8. **newtype 把单位/ID 编进类型**，比注释和命名更可靠
9. **泛型约束放在需要它的 `impl` 上**，不要给整个类型加不必要的约束
10. **方法不要过长**：一个方法一个业务动作，`&mut self` 的可见副作用越小越好

## 常见陷阱

1. **依赖字段顺序/大小**：`repr(Rust)` 会重排字段；按字节读写请用 `#[repr(C)]`
2. **`#[repr(packed)]` 取字段引用**：可能产生未对齐引用（E0793），属于 UB 风险；
   需要打包协议时用显式序列化
3. **更新语法后继续用整个结构体**：`..base` 移动了非 `Copy` 字段，
   `base` 只能访问未移动的字段，整体使用会 E0382
4. **`Default` 派生失败**：所有字段都必须 `Default`；有特殊默认值就手写 `impl Default`
5. **调用 `self` 方法后继续用原值**：方法已经把值移走，E0382；
   想保留就改成 `&self`/`&mut self`
6. **对不可变绑定调用 `&mut self` 方法**：E0596，绑定要加 `mut`
7. **同一表达式里混用 `&self` 与 `&mut self` 方法**：E0502；
   拆成两条语句或先取出需要的值
8. **元组结构体字段名缺失**：只有 `.0`/`.1`，可读性差时改命名结构体
9. **误以为 `new` 是语言关键字**：它只是约定；`Default` 也不会自动调用
10. **固有方法与 trait 方法同名**：固有方法静默优先；要调 trait 版本用
    `Trait::method(&value)`
11. **泛型方法缺约束**：在 `impl<T>` 里调用 `T: Ord` 的方法会编译失败；
    把方法放到 `impl<T: Ord>` 里
12. **结构体字面量访问私有字段**：跨模块时字段私有，必须用构造器/方法（第 11 课）
13. **实现 `Drop` 的结构体部分移动**：E0509，析构需要完整值
14. **newtype 忘记委托 trait**：`Meters` 不会自动拥有 `f64` 的 `Display`/`Add`，
    需要手动实现或 `#[derive]`

## 练习

1. 写 `struct Counter { count: u32 }`，提供 `new`、`increment(&mut self)`、
   `reset(&mut self)`、`value(&self)`，并解释每个接收者为什么这样选。
2. 实现 `BankAccount`：`deposit(&mut self, amount: i64) -> Result<i64, String>`、
   `withdraw(&mut self, amount: i64) -> bool`，要求处理溢出与负数。
3. 写 newtype `Celsius(f64)`，提供 `new`（校验绝对零度）和 `from_fahrenheit`，
   并说明为什么 `from_fahrenheit` 可以直接返回 `Self` 而不需要 `Option`。
4. 实现泛型 `Stack<T>`，增加 `peek(&self) -> Option<&T>`，解释返回值的生命周期
   为什么与 `&self` 绑定（第 07 课）。
5. 定义 `struct A { a: u8, b: u64, c: u8 }` 与 `#[repr(C)]` 版本，
   打印 `size_of` 并手算 padding，解释差异来源。
6. 用更新语法从 `base` 构造 `dev`，打印哪些字段被移动、哪些被复制，
   并解释为什么 `base.port` 之后还能用。
7. 给一个类型同时定义固有方法 `name` 和 trait 方法 `name`，
   分别用 `value.name()` 与 `Trait::name(&value)` 调用，观察结果。
